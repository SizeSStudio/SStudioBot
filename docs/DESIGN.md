## 术语
- **主**：跑核心进程的那台机器和核心进程本身；同一时间一个，哪个系统都能当（§办3.1）。不单写「主」指对话角色。
- **主 agent**：主上和我对话的角色，用 pi 跑（§办1.1、§办1.2）。**reflect** 是它在复盘、前瞻、起局场景里（§参3）。
- **节点**：主动连主的机器，上面跑现成的 agent（Claude Code、Codex、pi，其余走 ACP）（§办3）。节点角色 `node` 批不了审批、答不了看一眼。
- **lane**：一个会话或一个任务是一条 lane；一条 lane 同一时刻只有一个 run（§底1.2）。
- **主对话 lane**：我和主 agent 主线对话所在的会话：飞书私聊、客户端 `console:main`，以后别的渠道也一样（§底1.1）。
- **run**：被事件叫醒跑一轮，跑完存好状态退出（§底1.2）。
- **推、看、对话**：触点三层；**看**是我自己去翻的那一层（§触1）。
- **看一眼**（看一眼卡）：卡在那里等我答的卡：权限请求、`ask`、熔断停下问我。进 `approvals`，只认我答（§办3.3）。
- **通知**：不拦人、不用我答，不进 `approvals`，走 §触1.1 路由表。
- **审批卡**：以我名义对外等 L2 动作要我批的卡（§底3.2）。
- **L0 / L1 / L2**：动作分级：自由、内部写、对外或以我名义（§底3.1）。
- **来源标签**：`owner@<surface>`（我亲手发的）、`job@<名字>`、`system@<类型>`，跟着 `ownerTyped` 走（§底2.1）。
- **D 级**：权限、预算、auto 规则和改进机制本身，只由我定（§进2.3）。
- **※**：评审或按原则推出来、改了我定过的行为的条目，不对就否。
- **五环**：办 → 读 → 参 → 觉 → 改 → 回到办（§0）；**分寸**（§寸）横切五环。
- **lens / 镜头**：八字、紫微、六爻等看法；lens 是跑它的那一件，断网（§参1、§参3）。
- **dream**：每晚整理记忆的 run（§读1）。
- **RSI**：越用越好：§进1 按我说的贴近我，§进2 是它自己越用越会办事。
- **seed**：`core/seed/` 里新实例的起点文件，改过的不覆盖（§底1.5）。
- **`work` / `personal`**：客户端 thread 两类；`personal`（主对话、`self/`、命盘、身体）不进群和工作台（§触6.5、§读5.1）。
- **`sbot-w` / `sbot-h`**：服务器上跑活的两个系统账号：`sbot-w` 无特权、出网受限；`sbot-h` 主机模式，有完整 sudo（§底3.6）。
- **中继**：端到端加密的中继，客户端和节点经它连主，只转密文（§触6.7）。
- **FlClash**：我安卓上常开的代理客户端；占着 VPN，所以手机不装 Tailscale（§触6.7）。
- **rustfs**：服务器上自建的 S3 兼容对象存储，现在只放加密后的备份（§底1.3）。
