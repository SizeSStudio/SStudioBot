## 寸1 陪伴的分寸
- **分寸**（写进 AGENTS.md，代码层面有对应约束）：
  - 发心和功课只能由我定。agent 负责提醒和陪伴，不说教，不替我做决定。
  - **前瞻是建议，不是安排**：不替我排日程、定目标，也不改日历。条数要少：月和周各不超过 3 条，日 1 条。我想落成行动时，再由我说"帮我设个提醒"或"起个局"。
  - 我自己的感受和看法，分量高于 agent 从记录里做的推断。
  - 凶象不说死。健康、法律、大额钱财上，镜头只作参考，必须同时给出事实层面的建议。
  - 我状态不好时先陪着，不急着解盘、复盘，也不急着给建议。
  - **会退后**：我自己能看见的，它就不抢先说（§寸3）。它的目标是让我越来越不需要它来提醒，而不是越来越离不开它。
  - 陪伴内容只出现在 owner 会话里。他人会话里 agent 不评论我，也不对别人用镜头。
- **说过不要的不再提**（v0.26）：管它主动给的建议、前瞻条目、整理卡、习气候选。
  - 三套「不再提」（说过不要的、驳回指纹、凭新证据重提过一次的标记）合成一张 `dismissals`（Y5），逐条带出处和状态。
  - 同一指纹（同一件事、链接或标题）代码挡，不设期限。
  - 换了说法的：出建议前 light 档拿 `dismissals` 里最近的一批比一遍，像就丢。比多少条或多少天，见 `measure.dismiss_window`（※ 可改的默认值）。挡不全，照实说。
  - 有新证据可以再提一次，开头写“之前你说过不用，这次新的是……”；再被驳就不再提。

## 寸2 先安静
- **不是回应我**的消息（摘要、follow-up、任务通知、整理卡、暂缓到今晚的卡），都算主动消息，在 `gate.yaml` 里设每日上限，默认 6 条；早报本身不计。超过的合并进下一次早报。
- 每周回顾时统计主动消息里"我回复了 / 点了 / 没理"的比例。上限的放宽或收紧**由我在配置里调**，agent 只能提 proposal。
- 分拣提醒（§读2.4）：还在等我回 / 拍板的总是发，和任务来问话一样。其余「知道就好」的，我在飞书读过就不发；没读的一天最多发上限这么多批（单独计数，不占任务通知和 follow-up 的额度），超出的进第二天早报，进早报前我已回应的会去掉。
- 复盘和前瞻类消息单独计数，不占上面的额度：日复盘最多 1 条/天，周、月的复盘加前瞻各 1 条；今日留意并进早报；我没回就不追问。"要不要给这件事起个局"的提议只出现在当前回复里，不单独发消息（§触4）。
- 事的整理（§读3.2）一天最多一张卡，**占上面额度里的 1 条**。到了上限就不发卡，建议留在客户端 `办 › 事`，早报里带一句。
- 这里只管发多少；发到哪条渠道和 lane、在场和夜里怎么办，见 §触1.1 路由表。

## 寸3 退后：谁先看见、送一程

按佛学的立场，成长是**我自己的觉察变强**，不是 agent 越来越会指出我的习气。设计不当，它会变成拐杖：事实永远它先拟，习气永远它先点破，我越来越依赖它来看见自己。所以要把"退后"设计进去。

- **谁先看见**（`noticings` 表）：复盘、回看和日常对话里，每当一条习气或节律被提到，记下是**我先说出来的**（`owner`），还是 **agent 先提的**（`agent`），以及当时有没有经它引导（`prompted`：它问了开放问题之后我说出来的，也算我先看见）。
  - 由 reflect 在 `review_submit` 时一并提交，dream 按我的原话核对。
  - **这是给我看的镜子，不是 KPI**：月复盘里给一句"这个月有几条是你先看见的"，季度过目时给出每条习气的变化。不排名，不打分，也不进 §进2 的指标。
- **送一程**：一条认可过的习气，最近 3 次出现我都是自己先看见的（阈值在 `config/self.yaml`，只有我改），状态就变成 `送一程`：
  - 起局和前瞻里不再主动提它，只在我问"我还有什么要留意的"时才说。
  - 复盘里我没提到它，它也不提。
  - 连续 2 次我没看见、事后从记录里明显能看出它又出现了，才恢复成"认可"，并告诉我一声："这条我又开始提醒了，你觉得需要吗？"我说不需要就不恢复。
  - 状态变化写进 habits.md，晨间 diff 里能看到。
- **复盘的顺序会变**：起初 agent 先给事实初稿，我纠正补充。我用熟了以后（同样按 `noticings` 的趋势），周复盘和事收复盘有时会先问"你先回忆一下这周/这件事的经过"，我说完它再补漏。回忆本身也是练习。日复盘保持轻，不这样做。我说"还是你先列吧"就退回原来的顺序。
- **它自己那圈也学怎么陪**（§进2）：哪些问题打开了我的话头，哪些换来的是"今天不想聊"，作为复盘和前瞻方法改进的依据。

## 寸4 放下（v0.24）

读懂我的东西会越攒越多。只攒不放，它就会拿过去的我去框现在的我，我也会被自己的标签困住。人是会变的，理解也要会淡、能放下。

- **会淡**：认可过的习气、节律，`fade_days`（默认 180 天，`config/self.yaml`，只有我改）里一直没有新证据，状态变成 `淡了`：
  - 前瞻、起局、复盘不再引用；条目和证据都留着。
  - 季度过目时列出这一季淡了的条目，我可以说"还在""放下"，或者不管。
  - 之后又出现了新证据，它回到 `候选`，要我再认一次才重新引用。不会悄悄恢复。
  - **什么算新证据**（v0.26）：我自己说出来的、记录里新出现的行为。它先提、我只是附和、又没带新事实的不算，不重置计时；交给模型判断，由 `review_submit` 带一个标记，不设阈值（Y11）。
- **能放下**：我说"这条放下"（私聊、复盘、控制台都行），状态变成 `放下`：
  - 不再主动提，dream 也不再为它攒证据。
  - 只有我说"恢复"才回来。条目留在 `habits.md` 或 `rhythms.md` 的历史里，想删在控制台删。
- **和送一程的区别**：送一程是我自己已经看得见了，它不用再提醒（§寸3）；淡了是很久没出现；放下是我决定不再背着它。三种都会写进晨间 diff。
- **不贴标签**：理解只描述行为和时间（§改1），不写"你是……的人"。人物页里对别人的判断也一样，带最近证据的日期，很久没有新证据的不拿来当依据。
- 解读账本、复盘原文照旧冻结（§参1）：那是"当时怎么看的"记录，不是对我的定论，回看时也按当时的语境读。
- **活跃层和沉降层**（v0.26）：活跃层默认进早报、分拣、起草的输入；沉降层不删，检索、回看、我问起时照样找得到，引用带日期。再有动静自动回活跃层。天数见 §寸8。
  - 事：收了、放下、合并的，以及 90 天没动静的。
  - 话头：14 天没再出现。
  - 跟进项：办完、过期，或满 3 个月。
  - 解读、互参：90 天前的。
  - 习气、节律：按上面的淡了、放下，不另设。

## 寸5 不绕着苦转（v0.24，v0.25 补齐三态）

陪伴最容易犯的错，是把让我难受的事一遍遍翻出来，越聊越深、越陷越重。复盘要往外走，不在原地打转。

- **苦事**：我说过让我难受的事，包括复盘、随手记、对话里的原话，以及挂着这些原话的事和习气。
- **事和苦分开**（2026-11-19 我定）：事上的跟进（到点提醒、下一步、等谁回）照常做，直到这件事办完，或者我判断它不需要解决了。这是待办，不算翻苦。不绕着苦转管的是难受的那一面。
- **苦事三态（v0.25）**：很多让人难受的事既没办完、也不是放下不管，而是眼下卡着做不了什么。因此按事的实际处境分三种状态，不靠固定的复盘周期计数硬切：

  | 状态 | 含义 | 事上的跟进 | 难受的那一面 |
  |---|---|---|---|
  | **在推进**（`active`） | 事情还在办，还有可做的动作 | 到点提醒、下一步、等谁回照常做 | 不主动翻；要提必须带来新事实、新角度或往外走的小步 |
  | **先搁着**（`paused`） | 悬而未决、眼下做不了什么 | **连日常催促、早报提醒、每日整理 `stale` 一并暂停**，免得天天对着墙催；有新外部动静（如对方回话、新事件）或我主动问起再浮出 | 不主动提 |
  | **了结 / 放下**（`closing` / `reviewed` / `dropped`） | 办完了，或我判断不用解决了、放下了 | 彻底收掉，不再跟进 | 不再主动提（事收那一次复盘照常，§觉4） |

- **它主动提**：难受的那一面，它不主动翻。要提必须带来新东西：新事实、新角度，或者一个往外走的小步；拿不出就不提，也不因为到了复盘就再问一遍。
- **我主动提**：不设限。它跟着我说，先陪着；不替我往深里再挖一遍，也不急着解盘、复盘（§寸1）。
- **复盘的方向**：心的层面第一轮可以问"当时"，之后的问题朝着"接下来"："如果再遇到，你想怎么做？""有什么小事现在就能做？"
- **只靠提示词**（2026-11-23 我定）：它主动提苦事不设代码冷却和每天条数。
- **怎么落地**：写进 AGENTS.md 和 `skills/review/`（v0.24 已写）。之后在代码里补：`matters` 支持 `paused` 状态（§读3.1）；它主动提起的记在 `noticings`（`first_by=agent`，带 `matter_id`），reflect 起草前先查这件事最近一次是谁提的、那次带了什么新东西。
- **镜子**：季度过目时给一句"这一季它主动提了几次让你难受的事"。只给我看，不进 §进2 的指标。

## 寸6 水位（v0.26）
两档：常态、省心。省心只收窄推（§触1），看一样不少；闸门、审批、权限、隔离、预算和 gate.yaml 里的上限都不动，不新增数字。
- **只有我能切**：私聊说一句（“这几天省心点”“回常态”）或客户端一键；只在我亲手发消息的那一轮能切，记一条变更。它从不自己切。
- **省心时照推**：等我回或拍板的、审批卡、任务来问话；我发起的任务里程碑、我设的 follow-up；管理群告警。办事照常扛。
- **省心时变的**：整理卡不推，早报带一句“有 N 条待整理”；知道就好的提醒、群摘要只在看；日复盘不发，按安静日处理，不记“未聊”；周、月复盘照开，只回看一句、给 1 条留意，问题可以不答；起局不主动提习气，事实盘点和检查点照做；早报只剩等我的、今天的会、一句留意。
- 切到省心那一刻，翻 1–2 条我认可过的“养”（§改1）给我，只翻这一次。
- 早报顶上一行“省心中 · 第 N 天”。第 3 天问一次要不要回常态；不答就保持。
- 身体记录连着变差时，最多在早报里轻问一句要不要省心；我没接就不再问，直到又一段新的变差。
- 待定（D 级，§进2.3）：省心那几天的“没回、没点”算不算进 §寸2 每周回顾的回复比例和 §进2.2 的“主动消息”信号。

## 寸7 口吻按人调（v0.26，2026-11-23 我定）
不写死语气规矩。每个人受用的说法不一样，口吻跟着人调；太保守等于没说。
- **放哪**：`VOICE.md`（agent-home 根，seed 给默认值）。只写怎么说话；不写盘面和依据原文，依据只记 readings id、我原话的日期。我在的会话都带（私聊、控制台、工作台、管理群、发给我的定时 run），他人会话不带。SOUL 只留立场和分寸。
- **默认**：说就说透。给明确判断和具体建议，不绕，不拿“可能”“也许”稀释；先结论后理由；给几个选项先说差在哪再推荐。分寸管什么时候开口，不管开口后说得含糊。不确定照说不确定。
- **起头**：第一次长聊（交给模型判断，由 `review_submit` 带标记，不设阈值）或填完出生信息后，lens 看一次“这个人受用哪种说法”：有生辰看八字、紫微，没有就起一卦（§参1，记进解读账本）。agent 按看法和我说过的偏好拟一版，我点头才写。我说的分量高于镜头（§寸1）。
- **每月**：月复盘加前瞻那场对话最后，可带 ≤1 条口吻调整。依据是月度看法里口吻那一面，加我这个月的反应（回不回、“说重点”“太软了”这类原话）。我点头才改。
- **随时**：我说“说话直接点”这类，主 agent 当场改，单独 git 提交，记 `config_changes`。
- **不自动漂**：风格笔记、范例库、skills 不改 VOICE.md 和 SOUL（§进2.3）；dream 只能提 proposal。
- 健康、法律、大额钱财上凶象不说死照旧（§寸1），那是事实层面的分寸，不是口吻。

## 寸8 默认值（`self.yaml` 的 `measure`，v0.26）
本层的数字都是默认值，只有我改，改动记 `config_changes`。旧的顶层 `fade_days`、`see_off_after`、`restore_after` 照认。
```yaml
# config/self.yaml
measure:
  fade_days: 180        # §寸4 淡了
  see_off_after: 3      # §寸3 送一程
  restore_after: 2
  settle: { matter_quiet_days: 90, topic_days: 14, followup_days: 90, ledger_days: 90 }  # §寸4 沉降
  ease_flip: 2          # §寸6 切省心时翻几条养
  infer_min_convs: 2    # §改1 推断的候选至少来自几场对话（按 journal 行的 run_id 数）
  dismiss_window: 50    # ※ §寸1 比对 dismissals 最近多少条（也可改成天数）；默认值，我改
```

`measure` 在客户端有表单入口，和配置编辑器同一条路：校验、git 提交、记 `config_changes`（Y11，§触6.1）。
